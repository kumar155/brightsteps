# BrightSteps Learning App

Responsive kid-first learning app prototype for laptop and mobile.

## Included
- Maths: Addition with 10 generated questions and scoring
- English: Missing letters with picture prompts
- English: Jumbled sentence activity
- EVS: expandable subject/module structure ready for more quizzes
- Responsive UI optimized for mobile and 13-inch laptop browsers
- Data-driven module/question structure so new question types can be added later

## Run
npm install
npm run dev

Open http://localhost:3000
